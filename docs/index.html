bigtime kodi repo

Osobný Kodi repozitár s doplnkami pre domáce použitie.

Inštalácia

V Kodi: Doplnky → Inštalovať zo súboru zip → repository.bigtime z tohto repozitára, potom Inštalovať z repozitára.

YouTube

Doplnok plugin.video.youtube sa k YouTube Data API pripája cez vlastné OAuth prihlasovacie údaje majiteľa tohto repozitára. Používa sa výhradne osobne, na vlastných zariadeniach.
